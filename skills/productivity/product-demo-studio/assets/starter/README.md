# Optional single-demo Remotion starter

This starter contains no agreed creative specs. project.json begins unapproved with empty languages, formats, scenes and variants. Do not render it as a default demo.

Use the product-demo-studio interview to obtain the actual requirements. Populate this project from the confirmed brief, capture/supply the agreed footage, and adapt the composition to that brief. For a batch, use a separate project per creative demo and record each in the outer batch manifest. This starter implements C03, not seven native renderers.

Run npm ci and npm run render after supplying the required inputs. The script checks the brief and capture fields, renders selected locales/formats, and normalizes output pixels. Optional -- --browser-executable <path> selects an existing browser.

The starter requires live/supplied footage. For an agreed screenshot-only direction, use a suitable upstream workflow or deliberately adapt the composition; do not attest that stills are live product footage.

Capture definitions must use the actual product's selectors and safe data. Keep source footage, receipts and customer data out of the shared review site unless explicitly intended. Preserve original batch outputs when creating a selected demo's next revision.
